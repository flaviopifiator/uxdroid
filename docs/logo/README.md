# uxdroid logo

The antenna prompt: a terminal window with two antennas. The app is a program on your desktop, and the antennas say which kind.

| File | Use |
|------|-----|
| `mark.svg` | The mark on a light background |
| `icon.svg` | The app icon, on its own dark tile; reads on light and dark pages |
| `favicon.svg` | Small sizes, down to 16 px: the prompt alone |

Colors: accent `#2ed3a3`, ink `#0d1714`. The wordmark is set in JetBrains Mono ExtraBold.

The same mark appears in `uxdroid --help` (drawn with box characters), in the top line of `uxdroid tui` (`>_ uxdroid` in the accent color, from 60 columns), and as the server icon that `uxdroid mcp` gives MCP clients.
